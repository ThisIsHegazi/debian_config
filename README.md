# debian_config

A collection of personal Debian configuration and setup bash scripts for automating system configuration and maintenance tasks.

## Overview

This repository contains shell scripts designed to automate and streamline Debian-based Linux system configuration. These scripts help quickly set up and configure a Debian environment according to personal preferences and requirements.

## Purpose

- **System Configuration**: Automate common Debian system setup tasks
- **Environment Setup**: Configure shell environments and development tools
- **Maintenance**: Simplify system maintenance and configuration management
- **Reproducibility**: Ensure consistent system configuration across installations

## Contents

This repository includes bash scripts for various Debian configuration tasks. Each script is designed to be modular and reusable.

## Language

- **Shell (100%)**: All scripts are written in bash/shell

## Usage

Scripts in this repository can be executed directly or sourced into other configurations as needed.

## Notes

These are personal configuration scripts tailored to specific needs. Feel free to adapt and modify them for your own use.
